# 澳門中級維修電工技能測試 - 智慧刷題系統

> 本工具依據**澳門特別行政區政府 勞工事務局 2026 年最新修訂版《中級維修電工 技能測試題庫》**完整解析實作，專為電工證照考核與日常複習設計。

---

## ⚡ 題庫規模與覆蓋

- **總題數**：**920 題**（完整收錄無遺漏）
  - **是非題**：334 題
  - **單選題**：586 題（含 64 張高清電路圖與符號圖形）
- **六大核心篇章**：
  1. 工作規範與電工安全（150 題）
  2. 電工基礎（235 題）
  3. 電工儀錶測量（130 題）
  4. 低壓電器與照明電路（148 題）
  5. 電機與電氣控制（175 題）
  6. 電子技術基礎（82 題）

## 🚀 快速開始使用

本系統提供**兩種啟動方式**，無論電腦或手機均可無縫使用：

### 方式一：一鍵啟動（推薦）
- 直接在資料夾中滑鼠左鍵雙擊 **`run_app.bat`**。
- 系統將自動在預設瀏覽器中開啟 `http://localhost:8000` 即可開始刷題。

### 方式二：免安裝純離線模式
- 直接在資料夾中雙擊 **`index.html`**。
- 無須連網、無需安裝任何環境或伺服器，即開即練！

## 🎯 核心功能特色

1. **五大多元學習模式**：
   - 📖 **順序練習**：按照官方題庫編號循序漸進，即時反饋對錯與標準答案，自動記憶上次做題進度。
   - 🔀 **隨機刷題**：打亂題目順序，打破記憶慣性，全面檢驗真實理解。
   - 📝 **模擬考試**：按官方考試比例（是非 50 題 + 選擇 50 題）隨機抽題，具備 60 分鐘倒數計時、答題卡快速定位、交卷評分與成績報告單。
   - ❌ **自動錯題本**：凡作答錯誤的題目將自動加入錯題本，支援針對性重練，答對後自動遞減並消滅錯題。
   - ⭐ **重點收藏**：點擊星星圖示快速收藏重點題目與陷阱題，便於考前衝刺複習。
   - 🔍 **題庫全文檢索**：支援隨時輸入電工術語、法規或關鍵字（如「接地」、「阻值」、「漏電」），即時篩選並跳轉作答。

2. **鍵盤極速作答快捷鍵（電腦端）**：
   - **是非題**：按 `O` / `1` / `T` 判定為正確；按 `X` / `2` / `F` 判定為錯誤。
   - **選擇題**：按 `A` / `B` / `C` / `D` 或數字鍵 `1` ~ `4` 快速作答。
   - **導航切換**：按鍵盤方向鍵 `←`（上一題）、`→` 或 `Enter`（下一題）。
   - **收藏標記**：按鍵盤 `S` 鍵快速切換收藏狀態。

3. **貼心人性化設計**：
   - **答對自動下一題**：支援開關控制，答對後流暢推進，大幅提高刷題效率。
   - **答題卡跳轉網格**：點擊右上角「📋 答題卡」，直觀檢視已答對（綠）、答錯（紅）、未答（灰）狀態，隨點隨跳。
   - **題目圖片燈箱**：遇到電路圖、波形圖或符號題，點擊圖片即可高解析全螢幕放大檢視。
   - **深色護眼模式 (Dark Mode)**：點擊右上角 `🌓` 即可切換暗色調，夜間溫習不刺眼。
   - **數據備份與還原**：點擊右上角 `💾` 可將作答進度與錯題本匯出為 JSON 檔，換電腦或手機時點擊 `📂` 即可一鍵還原！
